# Scam Defense: AI Phishing Interceptor

## Overview:
An AI-Powered  browser extension and API designed to passively
intercept and analyze suspicious digital messages (emails, SMS) for
Phishing and social engineering characteristics before a user
clicks on them.

## Tech Stack:
* Frontend: Vanilla Javascript (Browser Extension)
* Backend: Python, FastAPI, Langchain
* Database: Neon PostgreSQL
